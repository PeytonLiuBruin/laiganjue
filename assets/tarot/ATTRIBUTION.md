# Rider–Waite–Smith tarot illustrations

Original illustrations by **Pamela Colman Smith** (1878–1951), designed with Arthur Edward Waite, first published in 1909–1910.

These are scans of the original public-domain deck, not the recolored modern editions or their card backs. Public-domain status and an example scan: https://commons.wikimedia.org/wiki/File:RWS_Tarot_00_Fool.jpg

Image mirror: https://github.com/howlCode/tarot_api (the source README identifies the images as public domain). Exact source URLs and the verified card-to-atlas mapping are recorded in `sources.json`. No interpretation text from that repository is included.

The 78 scans are resized and packed into one local WebP atlas. The app applies the same CSS color filter, paper overlay, frame and highlight to every card; the original images remain recognizable. Card backs and the vector fallback come from the existing app. No live third-party image request is needed.

Atlas: 8 columns × 10 rows. Major arcana occupy slots 0–21 in card-number order; Wands 22–35, Cups 36–49, Swords 50–63, Pentacles 64–77. Court order: Page, Knight, Queen, King.
