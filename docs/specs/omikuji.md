# 御神签 omikuji · 模块规格

日本神社「おみくじ」：摇六角签筒 → 掉出一根写着番号的签棒 → 抽出签纸 → 大吉还是凶 → 凶签可以结在结绳架上。

## 内容（data.js）
- 运势等级与权重（浅草寺风格但柔化）：大吉 16 / 吉 30 / 中吉 10 / 小吉 10 / 半吉 6 / 末吉 8 / 末小吉 4 / 凶 12 / 小凶 2 / 半凶 1 / 末凶 1（合计 100；不含大凶或大凶 0）。
- **至少 50 支**原创御神签：`{ no:'第一番'…, level, waka:[4 行（和歌风的短句，中文，每行 5–9 字）], summary(总运 60–100 字，白话), items:{ 愿望, 待人, 失物, 旅行, 商卖, 学问, 争事, 恋爱, 转居, 出产, 病气, 缘谈 }(各 6–14 字，符合等级基调) }`。等级分布与权重大致相符（用 core.js 的 `pickLot` 先按权重抽等级再在该等级内均匀抽签）。
- 等级色：大吉 金 / 吉·中吉·小吉 朱 / 半吉·末吉·末小吉 墨 / 凶系 靛青（模块内 CSS 变量，浅色皮肤下要可读）。
- 结签说明文案、大吉带回文案、「一日一签为佳」提示。

## 视觉
- 舞台：一只六角木质签筒（CSS：六边形主体 + 顶部盖 + 底部小口，木纹用 `--wood-1/2` 重复渐变，筒身竖排「御神签」三字 + 「おみくじ」小字），摇动时整体摆动（强度分级 class）。
- 签棒：细长木棒，一端红漆，写「第十二番」。
- 签纸：白色和纸（`.paper-slip`，可加淡淡的樱花/波纹重复渐变），顶部大字等级（如「大吉」用等级色），下方 4 行和歌，再下方项目列表。
- 结绳架（凶签时）：舞台旁一根横杆，已结的纸条若干（storage 记录结签数量，最多显示 12 张）。

## 流程（三入口）
- `onShake` / 在签筒上 `gesture.drag` 来回 / 主按钮「摇签筒」`primary`（自动摇 1.2s）。摇动中 `rattle` 音效 + `haptic.rattle`。
- 出签：签棒从底部小口滑出（translateY + 微旋转，`clack`），显示番号；点签棒或按钮「取签纸」→ 签纸从抽屉/筒侧展开（scaleY 动画 + `paper`），等级大字用 `seal-stamp` 式盖章动画出现；大吉 confetti + `chime`；凶系 `low` 但文案温和。
- 弹结果抽屉；凶系抽屉 actions 含「结签」→ 签纸飞到结绳架打结动画（translate + rotate，`pop`），toast「厄运留在神社，好运带回家」；大吉/吉 actions 含「带回家」（confetti + toast）。

## core.js（可测）
- `LEVELS` 权重和 = 100；`pickLevel(rnd)` 分布近似权重（seeded 10000 次，误差 < 2%）；`pickLot(rnd)` 返回签且等级匹配；`validateLots()`（≥50，番号唯一，和歌 4 行，12 项齐全，每个等级至少 1 签）；`tieUp(state)`/`untie` 结签计数逻辑。

## 结果抽屉
kicker = 番号、title = 等级（等级色或 gold）、verse = 和歌 4 行、sections：总运 / 十二项目（用 stack + 两列网格 node）/ 备注（「一日一签为佳，凶签结于神社即可化解」）。actions：凶系「结签」「分享」；其他「带回家」「分享」。

## 细节
- 记录今日是否已抽（storage），再抽时 toast 提醒但不阻止。
- 结绳架数量 storage 持久化。
