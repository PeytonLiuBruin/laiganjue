# 六爻 liuyao · 模块规格

三枚铜钱掷六次成卦（金钱课），显示本卦、变卦、卦辞与白话解读。

## 起卦规则（core.js，必须正确且有测试）
- 每掷 3 枚铜钱，每枚 字(阳面, 记 3) / 花(阴面, 记 2)。三枚之和：6=老阴(×, 动爻, 阴变阳) / 7=少阳(—) / 8=少阴(- -) / 9=老阳(○, 动爻, 阳变阴)。
- 六次由下而上：初爻→上爻。本卦 = 六爻阴阳；变卦 = 动爻翻转后的卦（无动爻则无变卦）。
- 六十四卦查表：按 6 位阴阳（自下而上）→ 卦序(文王卦序 1–64) → 名称、Unicode 符号 `String.fromCodePoint(0x4DC0 + 序 - 1)`（䷀ 乾 … ䷿ 未济）。
- 上下卦（八经卦）名与象：乾天/坤地/震雷/巽风/坎水/离火/艮山/兑泽。
- 测试锚点：全阳=乾(1)、全阴=坤(2)、下震上坎=屯(3)、下乾上坤=泰(11)、下坤上乾=否(12)、下离上坎=既济(63)、下坎上离=未济(64)、下坎上乾=需(5)；老阳/老阴翻转正确；`hexagramFromLines()`、`changedHexagram()`、`coinsToLine([3,3,2])=7` 等。

## 内容（data.js）
- 64 卦每卦：`{ no, name, symbol, upper, lower, guaci(原文卦辞，短), xiang(象曰一句原文), gist(一句白话主旨), meaning(80–140 字白话解读), career, love, wealth, health(各 12–30 字), luck: 1–5 }`。原文卦辞/象辞可用通行本原文（公有领域）；白话必须自己写、具体。
- 六爻爻位通用释义（初/二/三/四/五/上，各 40–60 字，用于说明动爻所在的阶段含义）。
- 动爻数量说明：无动爻以本卦卦辞断；一动爻看该爻位；二至五动爻兼看变卦；六爻皆动以变卦断。

## 玩法（三入口）
- 体感：`onToss` 掷钱；`onShake` 也可触发（在手里摇钱再掷）。
- 屏幕：在铜钱区向上快滑（`gesture.flick`）。
- 按钮：主按钮「掷 钱」；附「自动连掷六次」（间隔约 1.4s）。
- 每掷：三枚铜钱飞起旋转（rotateX 多圈）落下（`coin` 音效 × 3，错落 60ms，`haptic.medium`），面朝上显示 字/花（铜钱用 CSS：圆形 + 中间方孔 `::after` 深色方块，正面写「字」或四字如"乾隆通宝"缩小，背面花纹）。
- 右侧/下方"卦象台"：六条横线自下而上逐条点亮，阳爻实线、阴爻断线，动爻加 ○/× 标记与微光。
- 六掷完成 → `gong`，卦名以大符号（Unicode 卦符 80px+）揭示，弹结果抽屉。

## 结果抽屉
kicker「本卦 · 上X下Y」、title = 卦名（如「水雷屯」）、verse = 卦辞原文、badge = 吉凶星级、seal（吉/平/凶/慎等一字）、sections：象曰 / 白话 / 动爻（列出第几爻动与释义）/ 变卦（名称+符号+一句主旨）/ 事业 / 感情 / 财运 / 健康。actions：「再起一卦」「分享」。

## 细节
- 显示「第 N 掷」徽记；防重入；卸载清动画。
- 卦象台在浅色皮肤下也要清晰（线条用 `var(--text)`/`var(--accent)`）。
