# 硬币骰子 coin · 模块规格

三个标签页：硬币 / 骰子 / 二选一。最轻快的一个模块，动效要爽。

## 硬币
- 舞台：一枚大硬币（直径 ≈ 150px）3D：`preserve-3d`，正面「字」（可写「正」或一枚古铜钱样式：圆形方孔，四字"来感觉"缩略也可），反面「花」（花纹：重复径向渐变/内联 SVG 简花纹）；侧边厚度用多层或 box-shadow 模拟。
- 三入口：`onToss` / 在硬币上 `gesture.flick` 向上 / 主按钮「抛 硬 币」`primary`。
- 动画：上抛（translateY −260px 再落回，抛物线 easing）+ rotateX 多圈（圈数由 intensity 决定 3–7 圈）+ 落地弹跳两次，`coin` 音效在起抛与落地各一次，`haptic.medium` 落地。落定面由 core 先决定，动画终止角度 = 圈数×360 + (正面 0 / 反面 180)。
- 结果：硬币下方大字「正 / 反」淡入 + 小徽章；累计计数「正 12 · 反 9」（storage），历史条最近 20 次（●○）。
- 「连抛 3 / 5 / 10 次」chips：快速连抛，统计多数（用于"三局两胜"）。

## 骰子
- 数量 chips：1–6 颗；类型：D6（默认）；可选 D20（用二十面体简化为大数字牌翻转即可，非必需）。
- 3D 骰子：CSS 立方体（6 面各自 pip 点数布局，白骰黑点或黑骰金点随皮肤），滚动 = translate 随机位移 + rotateX/Y 多圈 + 落定到目标面对应的旋转（face → rotation 映射表，core.js 可测），`thud` 逐颗落地 + `haptic.heavy`。
- 三入口：`onShake` / 在托盘上 `gesture.flick` 任意方向 / 主按钮「摇 骰 子」。
- 结果：每颗点数 + 总和 + 大小（≤10 小 / ≥11 大，3 颗时）+ 「豹子」提示；历史最近 10 次。

## 二选一
- 两个输入框 A / B（默认「做」「不做」），硬币两面写上 A / B 文字（自动缩字），抛法同硬币；结果大字显示胜出选项 + 一句判词（data.js 20 句风趣判词随机）。

## core.js（可测）
- `flipCoin(rnd)` → 'heads'|'tails' 公平（seeded 20000 次误差 < 2%）；`rollDice(n, sides, rnd)` 范围与长度；`diceRotation(face)` 6 个面映射各不相同且能把该面朝上（用单位向量旋转验证或表驱动测试）；`judgeBigSmall(values)`；`majority(results)`。

## 结果抽屉（可轻量）
硬币/二选一：resultCard 简短（title = 正/反 或 A/B，sub = 判词，sections = 统计）；骰子：title = 总和，sections = 点数、大小、彩蛋。actions：「再来」「分享」。也允许硬币模式不弹抽屉、只在舞台下方展示结果（但至少提供一个「详情」按钮弹抽屉以保持一致）。

## 细节
- 防重入；连抛期间禁用切换标签。
- 骰子托盘：舞台底部深色圆盘（`--stage-floor` 之上加一层）。
