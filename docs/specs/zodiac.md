# 星座 zodiac · 模块规格

西方十二星座今日运势 + 东方十二生肖运势（两个标签页）。

## 西方星座
- 12 星座：`{ id, name:'白羊座', en:'Aries', glyph:'♈', dates:'3.21–4.19', start:[3,21], end:[4,19], element:'火', ruler:'火星', quality:'基本', traits:[4 关键词], profile(80–120 字), strengths(30 字), weaknesses(30 字), match:['狮子','射手','双子'], stars:[{x,y}] 与 lines:[[i,j]]（星图：8–14 个点的近似星座连线，画在 0 0 100 100 视野） }`。
- 今日运势（`dailyRng(sign+date)` 稳定）：综合/爱情/事业/财运/健康 各 1–5 星；幸运色（12 色名 + 色值，显示色块）、幸运数字 1–99、速配星座（当日随机）、今日一句（data.js 池 ≥ 60 句，通用但具体、可执行，如"把拖了三天的那条消息回掉"）、宜/忌各一件小事（池 ≥ 30）。
- 选择星座：横向滚动的 chips（`chips(...,{scroll:true})`）或 12 宫圆环；记住选择；也可输入生日自动判定（`signFromDate(m, d)`）。
- 舞台：深色星空（径向渐变 + 随机小星点 CSS）上绘制该星座的 SVG 星图（点 + 连线，点有闪烁动画），倾斜手机时星图轻微视差（`onTilt` + `kit.parallax`）；点击星图/主按钮「看运势」`primary` → 展开运势卡（或结果抽屉）。

## 东方生肖
- 12 生肖：`{ id, name:'马', glyph:'午', years:[…近几个年份], element(五行), profile(80–120 字), traits:[4], match:['虎','狗','羊'], clash:'鼠' }`。
- 从出生年自动判定（用 `lunarFromYmd` 的 `getYearShengXiao()`，注意春节分界）或手选。
- 今日运势同上结构（`dailyRng('sx-'+animal+date)`）。
- 本年运势（当前农历年，如 2026 丙午马年）：与太岁关系：本命年(值太岁)=同支；冲太岁=六冲（子午 丑未 寅申 卯酉 辰戌 巳亥）；害太岁=六害（子未 丑午 寅巳 卯辰 申亥 酉戌）；刑太岁=三刑（寅巳申、丑戌未、子卯、午午自刑 酉酉 亥亥 辰辰）；三合（申子辰 亥卯未 寅午戌 巳酉丑）、六合（子丑 寅亥 卯戌 辰酉 巳申 午未）为吉。对每种关系给 60–100 字说明 + 建议（data.js），默认「平顺」文案。
- 舞台：一枚生肖圆牌（大字地支 + 生肖名）与十二地支环。

## core.js（可测）
- `signFromDate(m,d)` 边界：3/21 白羊、4/19 白羊、4/20 金牛、12/22 摩羯、1/19 摩羯、1/20 水瓶、2/18 水瓶、2/19 双鱼。
- `dailyFortune(key, date)` 同日稳定、跨日不同、星级在 1–5、幸运数字 1–99。
- `taiSuiRelation(animalBranch, yearBranch)`：午年：马=本命年、鼠=冲、牛=害、兔=破(可选)、虎/狗=三合、羊=六合；子年：鼠=本命、马=冲。
- `animalFromYear(y)` 用 lunar 计算（春节分界测试：2026-01-20 属蛇，2026-02-20 属马）。

## 结果抽屉
kicker = 星座/生肖 + 日期、title = 名称（含符号）、badge = 元素/五行、sections：综合(星级 node `kit.stars`) / 爱情 / 事业 / 财运 / 健康 / 幸运色(色块 node) / 幸运数字 / 速配 / 今日一句 / 宜·忌；生肖页额外「本年运势」。actions：「换个星座」「分享」。

## 细节
- 皮肤：星空舞台在浅色皮肤下仍用深色底（星图需要），边框用主题线色。
- 星级用 `kit.stars(n)`。
