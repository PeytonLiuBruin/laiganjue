# 水晶球 crystal · 模块规格

两个标签页：水晶球（问什么答什么）/ 灵摆（是非题）。

## 水晶球
- 舞台：一颗大水晶球（直径 ≈ 240px）：多层径向渐变玻璃球 + 顶部高光 + 底部折射暗影 + 球内 3–4 团模糊的雾（`filter: blur`，缓慢漂移的 keyframes）+ 星点闪烁；球下方金属/木质底座（CSS）。皮肤变化时雾色跟随 `--accent`/`--glow`。
- 问题输入框（可选）+ 模式 chips：「是非题」/「神谕」/「一字」。
- 充能（三入口）：`gesture.rub` 在球上摩擦（intensity 累加进度 0→1，雾加速、变亮、球体微微发光 `box-shadow`，`shimmer` 低音量节流播放）；`onShake` 每次 +0.35；主按钮「凝 视」`primary`（自动充能 1.5s）。
- 进度满 → 雾散（雾 opacity→0，中心浮现文字）：答案以 `kit.typewriter` 逐字出现在球内，`shimmer` + `haptic.success`；1.2s 后弹结果抽屉。
- 答案池（data.js）：
  - 是非题：20 句经典魔法 8 号球风格中文（10 肯定 / 5 中立 / 5 否定，如「毫无疑问」「迹象指向是」「再问一次」「不要指望」「前景不妙」），按 5:3:2 权重。
  - 神谕：≥ 60 句原创诗性短句（12–24 字，意象具体，不鸡汤），每句附一条 20–40 字白话注解。
  - 一字：≥ 40 个字（静、行、舍、守、等、破、合、归、进、退、明、藏……）各附 30–50 字解。
  - 问题为空时 kicker 显示「你心里的那件事」。

## 灵摆
- 舞台：一根细链从顶部垂下，末端一颗水晶锥（CSS 三角/菱形 + 渐变），下方一张摆盘（圆形，上下「是」左右「否」，圆周「不明」）。
- 物理：简易单摆（`requestAnimationFrame`，状态 x,y 速度，阻尼），驱动源：`onTilt`（beta/gamma 变化量作为扰动）与屏幕拖动锥体（`gesture.drag` 松手给初速度）；开始后加入隐藏随机偏置力（`rng`）使摆逐渐收敛为三种模式之一：前后摆（是）、左右摆（否）、画圈（不明）；约 4–5 秒后判定（core.js `decidePendulum(rnd)` 先抽结果，动画朝该模式收敛）。
- 主按钮「开始问」`primary`（无传感器时自动给一个初速度）。
- 判定后：摆盘对应文字发光，`chime`（是）/`low`（否）/`pop`（不明），结果抽屉（简短：结论 + 一句建议 + 「灵摆只是把你心里已知的放大」提示）。

## core.js（可测）
- `pickAnswer(mode, rnd)`、权重校验、池大小校验（是非 20 / 神谕 ≥ 60 / 一字 ≥ 40 且无重复）；`decidePendulum(rnd)` 三种结果分布约 45/40/15；`pendulumStep(state, dt, bias)` 纯函数（数值稳定，不发散：跑 1000 步后有界）。

## 结果抽屉
水晶球：kicker = 模式、title = 答案（一字模式时超大单字）、sub = 问题回显、sections：注解 / 「换个问法」建议。actions「再问」「分享」。

## 细节
- 摩擦时手指处出现微光点（跟随 x,y）。
- 充能进度用球底一圈细环表现。
- 防重入：雾散过程中忽略输入。
