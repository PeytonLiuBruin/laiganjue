# 转盘 wheel · 模块规格

决定不了就转一下。手指一拨、手机一摇，转盘带惯性旋转，刻度声哒哒哒，停在哪就是哪。

## 预设（data.js）
- 今日运势：大吉 / 中吉 / 小吉 / 吉 / 末吉 / 平 / 小凶 / 凶（各附一句解语，data.js 每项 1–2 句）
- 吃什么：火锅 / 烧烤 / 日料 / 轻食沙拉 / 面 / 饺子 / 川菜 / 粤菜 / 自己做 / 随便（每项一句吐槽）
- 做不做：做 / 不做 / 再想想 / 问问朋友 / 明天再说 / 听心的
- 去哪儿：山 / 海 / 老城区 / 博物馆 / 公园躺平 / 商场 / 在家 / 随便走走
- 今晚干嘛：追剧 / 运动 / 读书 / 打游戏 / 早睡 / 学点东西 / 见朋友 / 发呆
- 真心话：8–10 个有趣的问题
- 自定义：文本域，每行一项（2–16 项），保存到 storage；可命名。
- 每个预设有一组配色（从主题变量派生：交替使用 `--accent`、`--surface-2`、`--accent-3` 与半透明），保证浅/深皮肤可读。

## 玩法（三入口）
- 屏幕：`gesture.spin(wheelEl, omega, {onMove})` 跟手旋转，松手按角速度惯性旋转（摩擦衰减，`requestAnimationFrame`；omega 太小时补一个随机最小速度并 toast「加点力」或直接给它一把）。
- 体感：`onShake` → 随机大力旋转；`onToss` 亦可。
- 按钮：主按钮「转 一 下」`primary`。
- 旋转中：每经过一个扇区边界播放 `tick` + `haptic.tap()`（节流，速度快时可隔格触发）；顶部的指针片（flapper）在过边界时轻微抖动。
- 停止：判定指针（顶部 12 点方向）所指扇区 → 高亮该扇区（放大/发光），`success` 或 `chime`，confetti，弹结果抽屉。

## 转盘绘制
- SVG（不用 canvas，便于换肤）：N 个扇区 path，文字沿半径方向排列（rotate 到扇区中心，文字过长自动缩字号或截断加省略号），外圈金边 + 小圆点刻度，中心圆帽写「转」。
- 直径 ≈ min(容器宽, 330px)。
- 指针：顶部倒三角，`var(--seal)`。

## core.js（可测）
- `segmentAt(angleDeg, n)`：给定转盘当前旋转角（顺时针正）与扇区数，返回指针所指扇区下标（顶部为 0°，扇区 0 从 −half 到 +half…，写清约定并测试边界）。
- `simulateSpin(omega0, friction)` 纯函数返回总旋转角与时长（用于测试和预计算）。
- `parsePreset(text)` 自定义解析（去空行、去重、上限 16、每项 ≤ 12 字）。
- 测试：segmentAt 在 0/90/180/359.9/720+ 等角度；parsePreset 边界；预设数据非空且项数 2–16。

## 结果抽屉
kicker = 预设名、title = 中奖项（gold）、sub = 该项解语、sections：「再转一次的理由」（幽默一句）/「去掉它再转」按钮（从当前候选中移除该项后重转，直到只剩 1 项）。actions：「再转」「分享」。
