# 灵签 qian · 模块规格

寺庙求签的完整体验：摇签筒 → 一支签跳出 → 取签 → 展开签纸 → 解签。

## 玩法（三入口）
- 体感：`ctx.motion.onMotion` 实时驱动签筒抖动（节流到 ~30fps，intensity 映射到签筒摆动角度与竹签上下跳动），`onShake` 触发"出签"。
- 屏幕：在签筒上左右快速来回拖动（`gesture.drag`，累计横向位移）也算摇；或长按主按钮"摇签"持续摇动，松手出签。
- 按钮：主按钮「摇签」（`primary: true`）— 点击后自动摇 1.2 秒再出签。
- 出签：一支竹签从筒口跃出（向上位移 + 轻微旋转，`whoosh`），落回筒边露出签号「第廿三签」；点击签或按钮「取签」→ 签纸（`.paper-slip`）从下方展开（scaleY / translateY 动画，`paper` 音效），签纸上竖排/横排签诗；然后弹出结果抽屉。
- 可选：问题输入框（40 字），结果里回显「所问」。

## 舞台视觉
- 签筒：竹节纹（重复渐变）圆筒 + 筒口一圈；筒内十几支竹签参差露头（每支不同高度、微倾），摇动时随机上下抖动。
- 背景：`kit.stage()`，可加一盏红灯笼 / 香案的暗示（纯 CSS，克制）。
- 出签的竹签上显示签号，字用 `var(--font-display)`。

## 内容（data.js）
- 至少 **64 支原创灵签**（不要照抄任何寺庙签文，避免版权/错漏；风格参照观音灵签：七言四句签诗 + 典故标题 + 等级）。
- 每支：`{ no, level, title(典故，如"姜太公钓鱼"), poem:[4 句七言], gist(签语一句), explain(解曰，80–140 字白话，具体不空洞), items:{ 功名, 求财, 婚姻, 健康, 出行, 失物 }(各 6–14 字) }`。
- 等级分布：上上 8 / 上吉 12 / 中吉 14 / 中平 14 / 中下 10 / 下下 6（合计 64；可更多）。下下签必须给出路，不恐吓。
- 印章字：上上「上上」, 上吉「上吉」…（seal 用 2 字）。

## core.js（可测）
- `drawLot(rnd)` 均匀抽取；`levelSeal(level)`；`validateLots(LOTS)` 返回问题数组（数量、编号连续唯一、四句七言、字段非空）。
- 测试：分布均匀性（seeded）、validateLots 为空、每个等级都有签。

## 结果抽屉
resultCard：kicker「第 X 签 · 典故」、title = 等级(gold)、badge = 「签诗」、seal、verse = 四句、sections：签语 / 解曰 / 六项分述（用 stack 网格）/ 所问（若有）。actions：「再求一签」「分享」。

## 细节
- 历史：最近 10 次签号与等级（`historyBar`）。
- 防重入；摇动中提示「诚心默念…」。
- 可选彩蛋：连续 3 次摇出同一支签 → toast「此签与你有缘」。
