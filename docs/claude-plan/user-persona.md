# 用户画像（18–30 岁）

来感觉的核心是「摇一摇、甩一甩，得到一句有感觉的话」。目标人群是把玄学当作情绪出口和社交话题的年轻人，不是要严肃算命的人。下面四个画像决定了视觉、付费和上架文案的取舍。

## 1. 小鹿 · 22 岁 · 大四学生，备考 / 找实习

- 场景：睡前躺在床上刷手机，考试和面试前一晚焦虑，想要一个「好兆头」。和室友一起摇签，截图发群里。
- 动机：情绪安慰、仪式感、好玩。最常用姻缘、事业签、塔罗每日一牌、御神签。
- 付费意愿：低到中。愿意为「一次性的好东西」付 6–18 元（比如一套好看的皮肤、一次深度解读），对连续订阅比较警惕，周订阅会直接劝退。
- 劝退点：界面像长辈用的算命 App（大红大金、密密麻麻的字）、广告弹窗、打开就要付钱、结果千篇一律。宣纸米色加小字会让她觉得「旧」。

## 2. 阿哲 · 26 岁 · 互联网运营，上班族

- 场景：通勤地铁上、午休时。每天早上看一眼今日运势和黄历宜忌，开会前摇一下事业签图个心安。
- 动机：日常习惯、小确幸、职场焦虑的出口。关心财运、贵人方位、吉时。
- 付费意愿：中。习惯为工具类 App 付年费（每年 98–198 元可以接受），前提是每天都会打开、有明显的增量（每日个性化运势、无限次深度解读、小组件）。
- 劝退点：加载慢、动画拖沓不能跳过、每次都要重新填生辰、结果页信息太散。

## 3. Mia · 24 岁 · 海外华人留学生 / 新移民

- 场景：异地恋、找工作、签证焦虑时打开。会用 Co-Star、Labyrinthos 这类英文 App，也想要东方的签和八字。
- 动机：文化认同 + 好看 + 能分享到 Instagram / 小红书。
- 付费意愿：中到高。已经习惯美区 App 的 $4.99–$9.99 月订阅，对年订阅 $29.99–$49.99 不敏感，前提是做得精致。
- 劝退点：只有中文没有英文提示、美术像国产页游、截图分享出去不好看。

## 4. 小橙 · 19 岁 · 大一新生，二次元 / 手游玩家

- 场景：课间、宿舍。把抽签当「抽卡」，喜欢收集和开箱的感觉，会连续摇很多次。
- 动机：好玩、可爱、可收集（签纸、器物皮肤、成就）。审美参照是皇室战争、魔兽兵团、原神这类明快卡通风格。
- 付费意愿：小额高频。6 元、12 元的「器物皮肤 / 签筒皮肤」最容易下手，不太会买订阅。
- 劝退点：画面阴沉、3D 有塑料感、动作没有弹性、没有收集和成长感。

## 共同结论

1. 视觉要「明快、圆润、有弹性」，像手游而不是像古籍。阴沉的雾、写实的金属反光、米色大底都在劝退。
2. 免费部分要让人每天回来（每日运势、每日一签），付费买的是「更深、更多、更好看」，不能卡住第一次体验。
3. 价格档以人民币 6 / 12 / 18 / 25 / 98 元和美元 $0.99–$49.99 为主，周订阅不做。
4. 结果页要适合截图分享（竖版卡片、带 App 名），这是最主要的免费获客渠道。
5. 需要英文界面才能覆盖画像 3 和美区商店。
