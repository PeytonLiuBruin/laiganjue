# 新视觉方向：明快卡通 · 手游质感

参照：皇室战争（Clash Royale）、魔兽兵团（Warcraft Rumble）。关键词是「饱和、圆润、手绘感的分段明暗、深色描边、弹性动作、晴朗天空」。目标是让每件 3D 器物像手游里的道具卡，一眼看上去可爱、有分量、想去摇它。

## 1. 现状问题（第一轮截图）

- 器物用 PBR 材质（MeshStandard / MeshPhysical，金属度 1、清漆、室内环境反射），在软光照下显得像塑料玩具。
- 雾从 8–9 米开始，天空是米黄色，加上 Neutral 色调映射，整体灰、暗、低饱和。
- 没有轮廓线，器物和背景混在一起，在小屏上读不出形状。
- 舞台右上角默认显示「FPS」，像调试界面。
- 页面主体是米色底、细线字，器物舞台被体感授权卡和生辰卡挤到首屏下半部分。

## 3. 界面（2D）方向

- 背景：浅色皮肤从米色宣纸改为奶油白到浅天蓝的渐变（#fffaf0 → #eaf6ff），卡片纯白、圆角 20px、底部 4px 同色深一档的「厚度边」，像手游按钮。
- 主按钮：高 56px、圆角 18px、饱和渐变（红 #ff6a4d → #e8463c），底部 4px 深色边，按下时下沉 3px。
- 字体：标题用系统圆体（`"PingFang SC", "SF Pro Rounded", system-ui`，字重 700–800），正文 15–16px、行高 1.6。减少衬线宋体的使用，只在签诗正文保留。
- 图标：线框图标改为双色填充图标（主色 + 浅色底），线宽 2px，圆头。
- 首屏：玩法页的 3D 舞台上移到首屏上半部，体感授权改为舞台下方一行轻提示（点开再授权），生辰卡折叠成一个小按钮。
- 动效：卡片进入 220ms 弹出（cubic-bezier(.34,1.56,.64,1)），按钮按下 90ms。
- 首次引导卡（第 36 轮）：和 App 图标同一枚金币，68px、径向金 #fff1b0 → #ffc93c → #e3a21a、3px #8a3a10 描边与 4px 同色厚边，中间红字「感」#e8463c 配 2px #5a1a10 八向描边，出现时 0.6 秒从 0.4 倍转 −18° 弹到原位。标题圆体 900、28px。三行说明各放在浅底圆角条里，左边 42px 描边方块（红 #e8463c / #6e1712、蓝 #3d8bff / #173a80、紫 #9b6bff / #3a2380），白字 1.5px 四向描边，底部 3px 厚边。卡片 2px 边、圆角 26、底部 6px 厚边。

## 4.2 触控目标（第 30 轮）

- 所有可点元素的点按区域至少 44×44 px（Apple 人机界面指南 44 pt）。新控件写完后跑 `node scripts/tap-audit.mjs`，结果应为 0。
- 外观要紧凑的小控件不放大外观，用透明 `::before`（`position: absolute; inset: 负值`）把点按区域扩到 44，相邻元素的扩展区域不能重叠（扩展量不超过间距的一半）。
- 统一写在 `src/styles/touch.css`，它是样式入口的最后一层。正文里的行内文字链接属于指南的例外。

## 4.3 文字对比度（第 31 轮）

标准按 WCAG 2.1 AA：正文 ≥ 4.5，大字（≥ 24px，或 ≥ 18.66px 且粗体）≥ 3。不可用的按钮豁免。用 `node scripts/contrast-audit.mjs` 逐页逐皮肤审计（21 个页面 × 5 套皮肤），参数集中在 `src/styles/contrast.css`。

- 主色用作文字时一律用 `--accent-text`，不直接用 `--accent`。宣纸 `#b8302a`（白底 6.0，天蓝底 5.5，选中胶囊浅红底 4.6），青瓷 `#1f5546`，朱砂 `#f6d27a`，星穹 `#d7cdff`，玄墨沿用主色。主色本身（按钮底、图标、进度条）不变，保持明快。
- 主按钮、选中页签、转盘中心字、付费卡印章是白字压亮红渐变（白对 #ff6a4d 只有 2.8），宣纸与青瓷给白字加一圈 1 到 1.5px 的厚边色描边再往下 2.5px，像 Clash Royale 的按钮字。白字对描边 `#b8302a` 为 6.0。
- 第三级文字：宣纸 `#67617f`，青瓷 `#3d524b`（第二级 `#31453f`），玄墨 `#a3aaa0`，朱砂与星穹由 42% 到 45% 不透明提到 60% 到 62%。
- 黄历纸页在所有皮肤下都是金黄底，红 `#9e2a22`、绿 `#245c42`，原来靠 opacity 变淡的小字改实色 `#6a5528`。
- 不要再用 opacity 把 10 到 12px 的小字调淡，要淡就换一个通过审计的颜色。
- 浮在 3D 舞台上的字（角标、提示）背后没有底板时，用 `node scripts/contrast-audit.mjs --stage` 开 WebGL 截图取样，取最差 10% 分位的像素算对比度，同样要 ≥ 4.5（第 32 轮）。新加舞台文字时，亮天空上用深色字，夜空上用浅色字，两者都过不了就加半透明底板或 Clash Royale 式深色描边。

## 5. 落地位置

- `src/ui/stage/toon.js`：卡通着色（改写 PBR 材质的光照）、硬高光、边缘光、反向外壳描边，在 `engine.js` 构建场景后统一套用。
- `src/ui/stage/atmosphere.js`：五套皮肤的天空、水、光照参数。
- `src/ui/stage/scenes/common.js`：MAT 里的材质颜色改为上面的色板。
- `src/styles/themes.css`、`components.css`：2D 界面的色板、卡片厚度边、按钮。
- `src/ui/solid-scene.js`（筊杯、硬币、骰子、六爻铜钱）、`src/ui/stick-scene.js`（灵签筒、御神签筒）、`src/modules/plinko/scene.js`（落球盘）：画布 2D 器物，同样用三段明暗、硬高光与本色加深的外轮廓（线宽约 3.4px × 场景缩放，最小 2.4px），色板与第 2 节一致。
