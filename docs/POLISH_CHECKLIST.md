| --- | --- |

| 八字 | 改生辰或性别立即清除旧命盘、五行和解读；未知时辰明确显示；模型无需闪烁唤醒 |

| 卢恩 | 重力、摩擦、递减回弹与接触反馈；符石厚度和连续翻面；键盘操作、阅读锁与卸载清理 |
| 星座 | 恢复无效的旧选择；生日范围校验；删除模型移出视口再移回的唤醒办法；幸运色对比 |
| 水晶球 | 问题保存并随本轮保留；灵摆与球体切换重置；删除隐藏闪烁；低动态模式减少常驻绘制 |
| 御神签 | 动画期间锁定结绳架入口；取消纸张拖动处理动画 Promise；紙面与落点反馈 |

共用界面：14 个本地实物图案；弹窗只从顶部拖动关闭，支持嵌套焦点和页面滚动位置恢复；标签切换保留 DOM、焦点和禁用状态；按钮与角标换行；小屏、横屏、安全区和长标题排版。共用立体模型在挂载后首帧重新测量尺寸，无需隐藏或移走模型。

验证：`npm test` 264 项通过，`npm run build` 通过。DOM 与 Canvas 组件验证覆盖 14 个完整玩法、塔罗五牌阵、卢恩单符/三符/五符、输入锁定、结果一致、主动阅读、重置、嵌套弹窗、动画取消与卸载。连续体感验证覆盖 D6/D20 长时间晃动、停顿再摇、按钮接入体感不重抽本轮结果，以及两种签筒连续晃动、收手出签和再次摇动。

组件验证使用模拟输入与时间；系统传感器权限和实际振感需在支持的手机浏览器上体验。
